go### $ How to Install

Open the terminal and type following commands.

* `apt update`

* `apt install git -y`

* `apt install python -y`

* `pkg install python-pip`

* `git clone https://github.com/siftifybd/BOMB-X.git`

* `cd BOMB-X`

* `chmod +x *`

  
* `./run` if not running `python main.py`
